# ebookFGTS

Projeto com o objetivo de gerar um ebook digital com as facilidades das ferramentas de IA. 

💻 Tecnologias utilizadas no projeto
ChatGPT
Meio da jornada
PowerPoint
🧠 Solicita
ChatGPT:
Ação prompt
título Crie um título de um ebook sobre o tema de fgts na moradia própria, conforme as regras do Manual da Moradia Própria, me liste 5 variações de títulos
conteúdo 
A partir da criação do título,, fui melhorando a interação com o chat e pedindo pra ele me trazer os principais pontos que constam no MMP, como quando utilizar o FGTS e os documentos necessários para a utilização.
